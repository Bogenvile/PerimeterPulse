Features

Everything You Need

A single lightweight agent on each PC sends real-time telemetry to your server. No cloud dependency.

Hardware Monitoring

Real-time CPU usage, RAM consumption, storage utilization, and uptime with interactive time-series charts.

Disk Health Scoring

Health percentage for SSD & HDD. SMART Wear detection. Color warnings when health drops below 90%.

Network Diagnostics

WiFi signal strength, link speed, gateway IP, DNS check, internet reachability, and ping latency.

Location Tracking

GPS & GeoIP location with Leaflet maps. See all your PCs plotted on a world map in real-time.

Remote Commands

Execute shell commands on any agent. Kill processes, run diagnostics, restart services — from the dashboard.

Process Manager

Top processes by RAM with app window titles. Kill misbehaving processes with a single click.

Alert Notifications

Telegram & email alerts on status changes. Configurable thresholds for CPU, RAM, and storage.

Auto-Updates

Agents check for new versions every 5 minutes. Download, self-replace, and restart automatically.
