PerimeterPulse is a self-hosted, open-source monitoring platform. Deploy lightweight agents on your computers and track CPU, RAM, disk health, network status, and location — all in real-time. PerimeterPulse adalah platform monitoring open-source self-hosted. Pasang agent ringan di komputer Anda dan pantau CPU, RAM, kesehatan disk, status jaringan, dan lokasi — semuanya real-time.

Everything You NeedSemua yang Anda Butuhkan

A single lightweight agent on each PC sends real-time telemetry to your server. No cloud dependency.Satu agent ringan di setiap PC mengirim data real-time ke server Anda. Tanpa ketergantungan cloud.

Hardware MonitoringMonitoring Hardware

Real-time CPU usage, RAM consumption, storage utilization, and uptime with interactive time-series charts.CPU, RAM, penyimpanan, dan uptime real-time dengan grafik time-series interaktif.

Disk Health ScoringSkor Kesehatan Disk

Health percentage for SSD & HDD. SMART Wear detection. Color warnings when health drops below 90%.Persentase kesehatan SSD & HDD. Deteksi SMART Wear. Peringatan warna jika kesehatan di bawah 90%.

Network DiagnosticsDiagnostik Jaringan

WiFi signal strength, link speed, gateway IP, DNS check, internet reachability, and ping latency.Kekuatan sinyal WiFi, kecepatan link, gateway, DNS, konektivitas internet, dan latensi ping.

Location TrackingPelacakan Lokasi

GPS & GeoIP location with Leaflet maps. See all your PCs plotted on a world map in real-time.Lokasi GPS & GeoIP dengan peta Leaflet. Lihat semua PC di peta dunia secara real-time.

Remote CommandsPerintah Jarak Jauh

Execute shell commands on any agent. Kill processes, run diagnostics, restart services — from the dashboard.Jalankan perintah shell di agent manapun. Matikan proses, diagnostik, restart layanan — dari dashboard.

Process ManagerManajer Proses

Top processes by RAM with app window titles. Kill misbehaving processes with a single click.Proses teratas berdasarkan RAM dengan judul jendela aplikasi. Matikan proses bermasalah sekali klik.

Alert NotificationsNotifikasi Peringatan

Telegram & email alerts on status changes. Configurable thresholds for CPU, RAM, and storage.Peringatan Telegram & email saat status berubah. Ambang batas CPU, RAM, dan penyimpanan bisa diatur.

Auto-UpdatesPembaruan Otomatis

Agents check for new versions every 5 minutes. Download, self-replace, and restart automatically.Agent memeriksa versi baru setiap 5 menit. Unduh, ganti sendiri, dan restart otomatis.
