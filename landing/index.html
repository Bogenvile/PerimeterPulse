Features

Everything You Need to Monitor

Lightweight Go agent (~9MB) deployed on each PC sends real-time telemetry to your self-hosted server.

💻

Hardware Monitoring

Real-time CPU usage, RAM consumption, storage utilization, and uptime tracking with time-series charts.

🩺

Disk Health Score

HDD Sentinel-style health percentage. SMART Wear detection for SSDs with color-coded warnings (green ≥90%, amber ≥70%, red <70%).

🌐

Network Diagnostics

WiFi SSID, signal strength, link speed, gateway IP, DNS check, and internet connectivity tests with ping latency.

📍

GPS & GeoIP Location

Track asset locations via GeoIP with Leaflet maps. See all your PCs plotted on a world map in real-time.

⚡

Remote Commands

Execute shell commands on any agent. Kill processes, run diagnostics, restart services — all from the dashboard.

🤖

AI Agent Assistant

OpenAI-powered chat that can view system data, run diagnostics, and execute commands. Full function-calling with tools.

📋

Process Manager

View top processes sorted by RAM usage with app window titles. Kill misbehaving processes with one click.

🔔

Alert Notifications

Telegram and email alerts when an asset goes warning or critical. Configurable status thresholds for CPU, RAM, storage.
